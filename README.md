# SOC Investigations 

A practical Security Operations Center (SOC) investigation portfolio focused on detecting, analyzing, and responding to simulated security incidents.

## Objective

This repository documents hands-on security investigations and demonstrates my ability to:

- Analyze security alerts
- Investigate logs and security telemetry
- Identify Indicators of Compromise (IOCs)
- Perform threat intelligence analysis
- Correlate events and build attack timelines
- Map attacker behavior to MITRE ATT&CK
- Determine incident severity
- Distinguish true positives from false positives
- Recommend appropriate incident response actions
- Document investigations clearly

## Investigation Methodology

Each investigation follows a structured SOC workflow:

1. Alert / Problem
2. Initial Triage
3. Evidence Collection
4. Hypothesis Formation
5. Log and Artifact Analysis
6. Event Correlation
7. Timeline Construction
8. IOC Investigation
9. MITRE ATT&CK Mapping
10. Scope Assessment
11. Severity Assessment
12. Verdict
13. Recommended Response
14. Lessons Learned
