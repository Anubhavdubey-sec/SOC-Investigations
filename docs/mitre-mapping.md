# MITRE ATT&CK Mapping

## Purpose

This document explains how attacker behavior identified during SOC investigations is mapped to the MITRE ATT&CK framework.

MITRE ATT&CK mapping is used to describe observed adversary behavior using standardized tactics and techniques.

---

# Mapping Process

```text
Observed Evidence
       ↓
Identify Attacker Behavior
       ↓
Determine Tactic
       ↓
Determine Technique
       ↓
Determine Sub-technique
       ↓
Verify Evidence
       ↓
Document Mapping
